3D Point Field Editor

Load a text file containing comma-separated x,y,z coordinates (one per line), adjust point positions directly in the scene, and export the updated data.

Tips

  • Click a point to select it.
  • Use the on-screen gizmo to drag points along an axis.
  • Use right mouse button to orbit and scroll wheel to zoom.
  • Use "Generate 16×16 plane" to reset to a uniform grid.
